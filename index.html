This desk is curated by Feri Andi (feriandi02), an independent security researcher. It answers one question for other independent hunters: which bounty programs are live, free, and open to a new researcher — and what gates do they carry? The program table, the checklists, and the findings log below are the desk's real content. The assistant at the bottom of the page is a network of three security agents that answer only from this data and from read-only public sources. It never invents findings, never touches keys, and never runs payloads.

Honest limits: the agents advise; the human files. Nothing here submits a report, moves funds, or signs anything. Program data is curated by the author and updated by editing this repo — it is not scraped live. The findings log lists closed or out-of-scope findings only, at a high level, with no exploit detail.

    How this site works

    BountyDesk is an open agentic website: it publishes machine-readable information about its agent network, and any visitor — human or agent — can discover and call it.

    • Manifest: agent-manifest.json (also at .well-known/awww.json) lists the network bounty_desk, its front agent bounty_desk_coordinator, and the network definition bounty_desk.network.json.
    • Agents: a coordinator that routes questions, a triage specialist (program triage), and a PoC specialist (PoC verification). The network runs entirely in your browser.
    • Your key, your provider: the assistant uses the AI provider key you enter in the settings below (bring your own key). Your key stays in your browser and is sent only to the provider you choose. You can also connect with OpenRouter for a free model in one click.
    • Trust before delegation: before this desk asks another agent site anything, it first asks Agent Atlas — an independent directory and trust checker — to check that site. You see a consent card (origin + purpose) and approve or decline first. The peer never receives your key.
    • What the desk cannot do: submit reports, move funds, sign anything, run payloads, or check a contract live on-chain (the contract-audit agent is a later milestone). The agents say so plainly when asked.
    • Open source: this site is a static site (HTML + CSS + vanilla JavaScript) in a public GitHub repository, built for the Open Agentic Web Challenge. The agent network, its instructions, and the site actions are all public and auditable.
